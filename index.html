Project Management

  1. Local Setup

    1. Open Git Bash
    2. Navigate to your projects folder
      cd ~/Projects
    3. Create project folder
      mkdir my-project
    4. Create subfolders
      mkdir assets assets/media assets/fonts
    5. Create Files
      touch index.html styles.css README.md .gitignore

  2. Collect Assets

    1. Move media (background images, logo, videos etc.) to assets/media
    2. Download .woff2 font files to assets/fonts/ and link in CSS using @font-face OR Select Google Fonts and copy the <link> tags directly into HTML <head>.
    3. Write standard HTML boilerplate to index.html
    4. Add CSS Reset & Base Rules to styles.css

  3. Version Control

    1. Configure .gitignore. Add to plaintext file, for now just with OS junk:
      .DS_Store
Thumbs.db
.vscode/
    2. Initialize Git & Make Initial Commit
      git init
git branch -M main
git add .
git commit -m "Initial commit: basic HTML/CSS setup"
    3. Create & Link Remote GitHub Repository
      1. On GitHub, click New Repository
      2. Name it my-project to match local folder name.
      3. Leave everything else unchecked (Don't create readme, .gitignore or license again)
      4. Click Create repository
      5. Run the following commands under or push an existing repository from the command line:
        git remote add origin https://github.com/your-username/my-project.git
git push -u origin main

  4. Deployment

    1. Publish the Live Site.
      1. On the GitHub repopage go to Settings > Pages
      2. Under Build and deployment > Branch set branch to main and folder to / (root).
      3. Click save.
      4. After 1-2 minutes hit refresh to get the live URL

  5. Daily Workflow

    1. Whenever you make changes to the code, follow this loop to update GitHub and the site:
      git add .
git commit -m "Describe what changed"
git push

HTML Reference

Standard HTML5 Boilerplate

<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Document</title>
  <link rel="stylesheet" href="styles.css">
</head>
<body>
</body>
</html>

Structuring & Headings

  • <h1> to <h6> — Headings (h1 is most important, h6 is least).
  • <p> — Paragraph text.
  • <div> — A block-level generic container for grouping content.
  • <span> — An inline generic container (e.g., for styling a single word).
  • <br> — Line break (empty tag, no closing tag).
  • <hr> — Horizontal rule/line (empty tag).

Lists

Lists always require a parent container and child list items.

<!-- Unordered (Bulleted) List -->
<ul>
  <li>First item</li>
  <li>Second item</li>
</ul>

<!-- Ordered (Numbered) List -->
<ol>
  <li>First step</li>
  <li>Second step</li>
</ol>

Tables

Data organized in rows (<tr>) and data cells (<td>).

<table>
  <thead>
    <tr>
      <th>Header 1</th>
      <th>Header 2</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Row 1, Cell 1</td>
      <td>Row 1, Cell 2</td>
    </tr>
  </tbody>
</table>

Links & Media

  • Links: <a href="url" target="_blank">Text</a>
    Note: target="_blank" opens the link in a new tab.
  • Images: <img src="path/to/image.jpg" alt="Description">
    Note: The alt attribute is critical for accessibility and broken links.

CSS Reference

Syntax & Selectors

CSS rules consist of a selector and a declaration block (property: value;).

/* Element Selector */
p { color: blue; }

/* Class Selector (uses a dot) */
.highlight { background-color: yellow; }

/* ID Selector (uses a hash) */
#main-nav { margin: 0; }

/* Grouped Selector */
h1, h2, h3 { font-family: Arial, sans-serif; }

/* Descendant Selector (Space) */
div p { color: gray; } /* Targets p inside div */

The Box Model

Every element in CSS is a box. From the inside out:

  • Content: The actual text or image.
  • Padding: Transparent space inside the border (pushes content inward).
  • Border: The line that goes around the padding and content.
  • Margin: Transparent space outside the border (pushes other elements away).
.box {
  /* box-sizing: border-box includes padding and border in the width */
  box-sizing: border-box; 
  width: 300px;
  padding: 20px;
  border: 2px solid black;
  margin: 15px auto; /* auto centers block elements */
}

Typography & Colors

.text-styles {
  /* Color */
  color: #333333; /* Hex code */
  background-color: rgb(240, 240, 240); /* RGB */
  
  /* Font */
  font-family: 'Helvetica Neue', sans-serif;
  font-size: 16px; /* or 1rem */
  font-weight: bold; /* or 700 */
  font-style: italic;
  
  /* Text Formatting */
  text-align: center; /* left | right | center | justify */
  text-transform: uppercase;
  line-height: 1.5;
}

Display & Positioning

.layout-rules {
  /* Display Flow */
  display: block; /* Takes up full width, starts on new line */
  display: inline; /* Only takes up necessary width, ignores top/bottom margin */
  display: inline-block; /* Inline flow, but respects width/height/margins */
  display: none; /* Removes element from the page completely */

  /* Positioning */
  position: static; /* Default flow */
  position: relative; /* Positioned relative to its normal place */
  position: absolute; /* Positioned relative to closest relative parent */
  position: fixed; /* Stuck to the viewport (screen) */
  position: sticky; /* Toggles between relative and fixed on scroll */
  
  /* Offsets (used with relative/absolute/fixed/sticky) */
  top: 10px;
  left: 20px;
  z-index: 10; /* Stacking order (higher numbers on top) */
}
